# README

This app was made from The Complete Ruby on Rails Developer Course on Ruby. I do not recommend the course, it is outdated and has been poorly updated. 

Mine is made using Rails 8, Ruby 3.4.3, and Bootstrap 5; the course was first developed for Rails 5 and has not been updated beyond Rails 6. Bootstrap does not play well with Rails, there are several Bootstrap features that don't work the way that they should or at all--Bootstrap can be a bear but I'm used to the trouble being it to do exactly what you want, not in the base functionality. But anyway, my goal was to learn Ruby/Rails and it was a solid intro to that.
